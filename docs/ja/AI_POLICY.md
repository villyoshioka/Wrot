# AI利用ポリシー

当ポリシーは、開発者が制作・公開する成果物において、AI アシスタントを活用するすべてのプロジェクトに共通して適用される基本方針を定めたものです。

開発における AI の活用範囲、AI に委ねていない領域、および運用上の遵守ルールを透明性をもって明記します。

---

## 採用している AI ツール

開発補助として **Claude**（Anthropic 社）を採用しています。

利用にあたっては [Claude 利用規約（Acceptable Use Policy）](https://www.anthropic.com/legal/aup) を遵守するとともに、独自の運用規定を設けて開発を行っています。

---

## AI の役割分担

設計や機能計画はすべて開発者が行い、AI に委ねることはありません。AI はあくまで開発者の指示に基づいてコードを具現化し、作業を補助するツールとして位置づけています。

### AI が担当する領域

| 担当範囲                         | 具体的な内容                                                                     |
| :------------------------------- | :------------------------------------------------------------------------------- |
| **コードの実装**（主目的）       | 開発者の指示・設計に基づく機能実装およびバグ修正コードの生成                     |
| **コード・セキュリティレビュー** | 実装されたコードの潜在的な不具合やセキュリティリスクの指摘（採否は開発者が判断） |
| **ドキュメント作成・更新の補助** | README、各種ドキュメント、リリースノート等の下書き作成・推敲補助                 |
| **リリース作業の補助**           | ビルド、アーカイブ作成、リリースノート反映などの定型コマンド補助                 |

### AI に委ねない領域（開発者が主導・判断する領域）

| 対象項目                           | 理由・方針                                                      |
| :--------------------------------- | :-------------------------------------------------------------- |
| **機能計画・設計・アーキテクチャ** | ユーザー体験や仕様の決定権はすべて開発者にあり、AI に委任しない |
| **ログイン・認証が必要な操作**     | セキュリティ担保のため、開発者が手動で安全に管理・実行          |
| **最終的な品質・挙動の保証**       | 実機での動作確認および手動テストを通じ、開発者が品質を担保      |
| **リリース可否の意思決定**         | 公開タイミングやマージの判断はすべて開発者が決定                |

> **重要**: すべての工程において、最終的な意思決定および承認は開発者（人間）が行います。AI はあくまで開発を補助・加速するための「ツール」であり、設計・仕様策定・リリースの判断主体は常に開発者にあります。

## 遵守事項

### 著作権・ライセンスの遵守

AI を用いた開発において、以下の事項を徹底しています。

- 第三者が権利を有するコードの無断コピー・剽窃の禁止
- 外部文章・公式ドキュメントからの無断転載の禁止
- 画像・アイコン等のメディア素材の無断流用の禁止
- 各種オープンソースライセンス条件に違反する実装の排除
- 著作権表示およびライセンス表記の改変・削除の禁止

すべての実装は正当なライセンスと権利に基づいて行われています。

### 倫理・セキュリティ基準

AI に対して、以下に該当するコードやコンテンツの生成を指示することはありません。

- マルウェア、バックドア、不正アクセス等の悪意あるコード
- ユーザーのプライバシー侵害やトラッキングを行うコード
- 意図的なセキュリティ脆弱性の混入
- 差別的・攻撃的・反社会的な表現やコンテンツ
- 虚偽の情報およびユーザーの誤認を招く設計
- 法令やプラットフォーム規約に抵触する機能の実装

### ユーザーデータの取り扱い

- ユーザーの個人情報やローカルデータを外部へ不当に収集・送信することはありません。
- 開発・デバッグプロセスにおいて、ユーザーの実データや個人情報を AI に読み込ませることは一切ありません。

## 開発者の責任

AI を活用した開発成果物について、開発者は以下の責任を負います。

1. **設計と仕様の策定**: すべての機能計画・アーキテクチャ設計を開発者自身が策定する。
2. **工程ごとのレビューと承認**: AI の生成コードを精査し、採用可否を判断する。
3. **実機検証による品質確保**: テストと動作確認を手動で実施し、安全性を確認する。
4. **最終リリースの担保**: 公開前にコードベース全体を点検し、整合性と安全性を最終確認する。

AI が生成に関わったコードやテキストであっても、成果物に対する最終的な責任はすべて開発者自身に帰属します。
