# 日時入力の使い方

投稿フォームで `@` を入力すると、時刻や日付を選んで入れられます。

---

## 基本の使い方

1. 行頭か、スペース（半角・全角）のすぐあとで `@` を入力します（全角の `＠` でも反応します）。
2. `00:00` から `23:45` までの時刻が、15分ごとに候補として表示されます。
3. 続けて数字を入力すると、候補が絞り込まれます。
4. 時刻を選ぶと、`@` が `20:00` のような時刻に置き換わり、後ろにスペースが入ります。

リスト・チェックリスト・番号付きリスト・引用の行では、記号のすぐあとで `@` を入力しても反応します。

### 候補の選び方

- **キーボード**: 候補は何も選ばれていない状態で開きます。`↓` キーで上から、`↑` キーで下から選び、`Enter` または `Tab` キーで確定します。選ぶ前の `Enter` はふつうの改行です。
- **マウス / タップ**: 候補をクリックかタップして確定します。
- `Esc` キーで候補を閉じられます。候補を選ばずに書き進めた場合、`@` はただの文字として扱われます。

### 絞り込み

- 先頭の 0 は省略できます。`@8` で `08:00`〜`08:45` が候補になります。`@2` では `02:00`〜`02:45` と `20:00`〜`23:45` が候補になります。
- 3桁か4桁の数字を入力すると、15分刻みでない時刻も候補に表示されます（例: `@830` で `08:30`、`@2037` で `20:37`）。
- 日本語入力のまま `＠２０` と入力しても、半角と同じように絞り込まれます。入る時刻は半角です。

---

## 今の時刻を入れる（@now）

行頭か、スペースのすぐあとで `@now` と入力して、スペースキーか `Enter` を押すと、押した瞬間の時刻（例: `14:32`）に置き換わります。15分刻みには丸めません。

- `@n` まで入力すると、候補に `@now` が表示されます。選択すると、その瞬間の時刻が入ります。
- 時刻に変わった直後に `Ctrl + Z` / `Cmd + Z` を押すと、`@now` に戻ります。
- 日本語入力のままだと `now` が「のw」になるため、`@now` は英字で入力してください。

---

## 日付を選んで入れる（@date）

行頭か、スペースのすぐあとで `@date` と入力して、スペースキーか `Enter` を押すと、日付を選ぶ画面が開きます。日付を選ぶと `@date` がその日付に置き換わり、後ろにスペースが入ります。日付は設定の「ヘッダー日付表示形式」と同じ形（例: `2026年11月24日`）です。

- `@d` まで入力すると、候補に `@date` が表示されます。選択すると、日付を選ぶ画面が開きます。
- スマートフォンとタブレットでは、ホイールが表示されます。回して日付を合わせ、下に表示される日付を押すと確定します。
- パソコンでは、入力した場所の下にカレンダーが表示されます。日付をクリックすると確定します。
- 選ぶ画面は今日の日付から始まります。過去の日付も選べます。
- 日付を選ばずに閉じると、`@date` はただの文字として扱われます。パソコンでは、カレンダーを開いたまま文字を入力したり消したりしたときも、カレンダーが閉じます。
- 日付に変わった直後に `Ctrl + Z` / `Cmd + Z` を押すと、`@date` に戻ります。

---

## 今日の日付を入れる（@today）

行頭か、スペースのすぐあとで `@today` と入力して、スペースキーか `Enter` を押すと、押した日の日付に置き換わります。日付の形は `@date` と同じです。

- `@t` まで入力すると、候補に `@today` が表示されます。選択すると、今日の日付が入ります。
- 日付に変わった直後に `Ctrl + Z` / `Cmd + Z` を押すと、`@today` に戻ります。
- `@date` と `@today` も `@now` と同じく英字で入力してください。

---

## リストで続けて時刻を入れる

時刻から始まるリスト項目の行末で `Enter` を押すと、次の項目は `@` が入った状態で始まり、時刻の候補がすぐに開きます。

- 時刻がいらないときは、`Backspace` を1回押すと `@` だけが消え、普通の項目に戻ります。続けて `Enter` を押すと、いつもどおりリストを抜けられます。
- リスト・チェックリスト・番号付きリスト・引用の中のリストで、同じように続きます。手動入力した時刻から始まる項目も対象です。

---

## 投稿時の桁そろえ

行頭や記号のすぐあとにある1桁の時刻は、投稿するときに2桁にそろえて保存されます（例: `9:30` は `09:30`）。文の途中に書いた時刻は変わりません。

---

## 困ったときは

### 候補が表示されない

- `@` が行頭か、リストや引用の記号のすぐあと、またはスペース（半角・全角）のすぐあとにあるか確認してください。文字に続けて書いた `@` では表示されないので、メールアドレスなどはそのまま書けます。
- コードブロック（`~~~` で囲んだ部分）や、`` ` `` で囲んだコードの中では、`@` を入力しても候補は表示されません。

### @now・@date・@today が反応しない

- 行頭か、リストや引用の記号のすぐあと、またはスペースのすぐあとにあるか確認してください。
- 日本語入力のまま入力していないか確認してください。
