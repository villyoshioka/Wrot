# 装飾の使い方

Wrot の投稿フォームには、テキストの書式を手軽に整えられるツールバーが付いています。
ボタンをクリックするだけで、太字やリスト、引用などの Markdown 記法を素早く挿入できます。

ここでは、ツールバーから利用できる装飾機能一覧と、それぞれの詳しい挙動について解説します。

---

## ツールバーの配置

投稿フォームの入力エリア下部に、初期状態では左から以下のボタンが配置されています。

| アイコン | 機能                     | 挿入される書式 / 動作                              |
| :------: | :----------------------- | :------------------------------------------------- |
|    🖼️    | **画像**             | ファイル選択ダイアログを開いて画像を添付           |
|    📎    | **埋め込み**             | `![[ ]]` によるノートやファイルの内部埋め込み      |
|  **B**   | **太字**                 | `**強調**`                                         |
|   _I_    | **斜体**                 | `*斜体*`                                           |
|    ☰    | **リスト**               | `- 箇条書き`                                       |
|    ☑     | **チェックリスト**       | `- [ ] タスク`                                     |
|    1.    | **番号付きリスト**       | `1. 番号付き`                                      |
|    ⋯     | **その他の書式メニュー** | コード・数式・引用・リンク・取り消し線・ハイライト |

※ ツールバーに表示するボタンの種類や並び順はカスタマイズ可能です。詳しくは [ツールバーの使い方](./ツールバーの使い方.md) をご覧ください。

---

## 太字・斜体の使い方

テキストの選択範囲がある場合と、ない場合（カーソルのみ）で挙動が異なります。

### テキストを選択している場合

選択範囲の前後を記号で囲んで装飾します。再度ボタンを押すと装飾を解除できます。

- **太字**: 選択テキストを `**…**` で囲みます。
- **斜体**: 選択テキストを `*…*` で囲みます。

### テキストを選択していない場合（予告モード）

入力位置へ先に**開始マーカーを挿入**し、入力を終えた段階で閉じる仕組みです。

1. ボタンを押すと、カーソル位置に開始記号（`**` など）が挿入され、ツールバーのボタンが点灯します。
2. そのまま装飾したいテキストを入力します。
3. 再度同じボタンを押すと、末尾に終了記号（`**` など）が挿入されて装飾が完了します。

> **便利な仕様と注意点**
>
> - **半角スペースの自動挿入**: 装飾を閉じた際、末尾記号の後ろに自動で半角スペースが1つ入るため、続けて次の文章を入力しても記号同士が干渉しません。
> - **未完了のまま投稿した場合**: 終了記号を入れずに投稿したときは、入力された記号（`**` など）がそのまま文字列として保存されます。
> - **太字と斜体の同時併用**: どちらか一方の予告モード中は、もう一方のボタンは押せなくなります。一度装飾を閉じてから次の装飾を適用してください。
> - **日本語入力（IME）中のガード**: 誤って装飾を閉じてしまうのを防ぐため、IME での文字変換中はボタンが一時的に無効化されます。

## リスト各種（箇条書き・チェック・番号付き）

ボタンを押すと、**カーソルがある行の先頭**に記号が挿入されます（行の途中にカーソルがあっても行頭に入ります）。

| ボタン             | 挿入される記号 |
| :----------------- | :------------- |
| **箇条書きリスト** | `- `           |
| **チェックリスト** | `- [ ] `       |
| **番号付きリスト** | `1. `          |

### 改行時の自動継続

リスト行で `Enter` キーを押すと、次の行にも自動で同じリスト記号が挿入されます。
内容を入力せずに空の状態で `Enter` キーを押すと、リスト入力を終了できます。

## その他の書式メニュー（⋯）

### コード

テキスト選択の有無によって、インラインかコードブロックかが自動で切り替わります。

| 状況                 | 挿入される形式                                                 |
| :------------------- | :------------------------------------------------------------- |
| **テキスト選択あり** | <code>\`選択テキスト\`</code>（インラインコード）              |
| **テキスト選択なし** | <code>~~~</code> 〜 <code>~~~</code>（フェンスコードブロック） |

※ フェンスブロック時はブロック内にカーソルが配置されるため、そのままコードを入力できます。

### 数式（LaTeX）

コードと同様に、選択状態によってインライン表示とブロック表示が切り替わります。

| 状況                 | 挿入される形式                     |
| :------------------- | :--------------------------------- |
| **テキスト選択あり** | `$選択テキスト$`（インライン数式） |
| **テキスト選択なし** | `$$ 〜 $$`（ブロック数式）         |

### 引用

選択行（または現在の行）の先頭に `> ` を挿入・解除（トグル動作）します。

- 複数行を選択した状態で実行すると、選択範囲内の全行に `> ` が付きます。
- すでに全行に `> ` が付いている状態で再実行すると、一括で解除されます。

### リンク

**テキストを選択している状態でのみ利用可能**です（未選択時はメニュー項目がグレーアウトします）。

- 選択したテキストを `[選択テキスト](URL)` の形に変換し、括弧 `()` の中にカーソルが移動します。

### 取り消し線・ハイライト

**テキストを選択している状態でのみ利用可能**です（未選択時はグレーアウトします）。再度選択して実行すると装飾を外せます。

| 機能           | 挿入される書式 |
| :------------- | :------------- |
| **取り消し線** | `~~テキスト~~` |
| **ハイライト** | `==テキスト==` |
