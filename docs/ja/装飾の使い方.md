# 装飾の使い方

Wrot の投稿フォームにはツールバーがあり、ボタンを押して太字やリスト、引用などの装飾を付けられます。

v3.0.0 から、投稿フォームは Markdown の記号を隠して、装飾した見た目のまま表示します。記号の消し方や装飾を重ねたときの決まりごとなど、フォームでの入力の動きは [投稿フォームの変更点について（v3.0.0 以降）](./Ver3.0.0以降の投稿フォームについて.md) をご覧ください。

---

## ツールバーの配置

初期状態では、投稿フォームの入力欄の下に左から次のボタンが並んでいます。

| アイコン | 機能                     | 保存される書式 / 動作                                                      |
| :------: | :----------------------- | :------------------------------------------------------------------------- |
|    🖼️    | **画像**                 | ファイル選択ダイアログを開いて画像を添付                                   |
|  **B**   | **太字**                 | `**太字**`                                                                 |
|   _I_    | **斜体**                 | `*斜体*`                                                                   |
|    ☰    | **リスト**               | `- 箇条書き`                                                               |
|    ☑     | **チェックリスト**       | `- [ ] タスク`                                                             |
|    1.    | **番号付きリスト**       | `1. 番号付き`                                                              |
|    ⋯     | **その他のメニュー**     | あとでピン留め・コード・数式・引用・リンク・取り消し線・ハイライトなど     |

※ 表示するボタンや並び順は変えられます。詳しくは [ツールバーの使い方](./ツールバーの使い方.md) をご覧ください。

## 太字・斜体

### 文字を選んでいる場合

選んだ文字を太字（斜体）にします。もう一度押すと外れます。

- ほかの装飾が付いた文字にも重ねて付けられます。太字と斜体も同時に付けられます。

### 文字を選ばずに押したとき

押すとボタンが点灯し、そのあと打つ文字が太字（斜体）で表示されます。もう一度押すと装飾を閉じます。

- 何も打たずに `Backspace` を押すと取り消せます。
- 閉じずに投稿した場合は、その行の終わりで自動的に閉じてから投稿されます。
- 点灯している間は、もう一方（太字なら斜体）のボタンは押せません。
- 日本語入力（IME）で未確定の文字がある間は、誤って閉じないよう点灯中のボタンが一時的に押せなくなります。

## リスト各種（箇条書き・チェック・番号付き）

ボタンを押すと **カーソルがある行** がリストの項目になります。行の途中にカーソルがあっても、記号は行の先頭に入ります。もう一度押すと元の行に戻り、別の種類のボタンを押すと種類が入れ替わります。

| ボタン             | 保存される記号 |
| :----------------- | :------------- |
| **リスト**         | `- `           |
| **チェックリスト** | `- [ ] `       |
| **番号付きリスト** | `1. `          |

- 引用の行で押すと、引用の中にリストを作れます。
- `Enter` での継続、`Tab` や `Backspace` での段の上げ下げなどは、[投稿フォームの変更点について（v3.0.0 以降）](./Ver3.0.0以降の投稿フォームについて.md) の「6. リストと引用の操作」をご覧ください。

## その他のメニュー（⋯）

### コード

文字を選んでいるかどうかで、インラインコードかコードブロックかが切り替わります。

| 状況               | 保存される形式                                                 |
| :----------------- | :------------------------------------------------------------- |
| **文字を選択あり** | <code>\`選んだ文字\`</code>（インラインコード）                |
| **文字を選択なし** | <code>~~~</code> 〜 <code>~~~</code>（コードブロック）         |

- コードブロックを入れるとブロックの中にカーソルが置かれ、そのままコードを入力できます。
- 装飾やリンクが付いた文字を選んでいるときは、ボタンが押せなくなります。
- コードブロックの中で `Tab` キーを押すと字下げが入ります。字下げにタブとスペースのどちらを使うかと、スペースの数は Obsidian の設定「タブの使用」「タブの間隔」に従います。改行すると、新しい行は前の行と同じ字下げから始まります。
- 言語名が `html`・`xml`・`svg`・`vue`・`svelte` などのコードブロックでは、開きタグの最後の `>` を入力すると閉じタグが自動で入ります。`</` と入力すると、まだ閉じていないタグのうち、いちばん内側にあるタグの閉じタグが補われます。
- 投稿メニューの **コードをコピー** で、コードブロックの中身だけをコピーできます。コードブロックが2つ以上ある投稿では、それぞれの1行目が一覧に並ぶので、コピーしたいものを選びます。

### 数式（LaTeX）

コードと同じく、文字を選んでいるかどうかで文中の数式か数式ブロックかが切り替わります。

| 状況               | 保存される形式                     |
| :----------------- | :--------------------------------- |
| **文字を選択あり** | `$選んだ文字$`（文中の数式）       |
| **文字を選択なし** | `$$ 〜 $$`（数式ブロック）         |

- 装飾やリンクが付いた文字を選んでいるときは、ボタンが押せなくなります。
- 投稿メニューの **数式をコピー** で、数式ブロックの中の式だけをコピーできます。数式ブロックが2つ以上ある投稿では、それぞれの1行目が一覧に並ぶので、コピーしたいものを選びます。

### 引用

選んでいる行か、カーソルがある行の先頭に引用の記号 `>` を付けたり、外したりします。

- 複数行を選んだ状態で押すと、選んだ行すべてに付きます。
- すでに全部の行に付いている状態で押すと、まとめて外れます。

### リンク

文字を選んでいるとき、またはリンクの上にカーソルがあるときに使えます。

フォームの下に入力欄が開くので、ノート名か URL を入力して `Enter` で確定します。詳しくは [投稿フォームの変更点について（v3.0.0 以降）](./Ver3.0.0以降の投稿フォームについて.md) の「7. リンクの追加と編集」をご覧ください。

### 取り消し線

**文字を選んでいるときだけ使えます。** 選んでいないときはグレーになります。もう一度押すと外れます。

| 機能           | 保存される書式 |
| :------------- | :------------- |
| **取り消し線** | `~~文字~~`     |

### ハイライト

**文字を選んでいるときだけ使えます。** 選んでいないときはグレーになります。

- 押すと色のメニューが開き、**デフォルト・赤・オレンジ・黄・緑・青・紫** から選べます。デフォルトはテーマのハイライト色です。
- ハイライトが付いた文字を選んでいるときは、メニュー名が **ハイライトを解除** になり、押すとハイライトが外れます。

| 色               | 保存される書式           |
| :--------------- | :----------------------- |
| **デフォルト**   | `==文字==`               |
| **赤〜紫の6色**  | `==🔴文字==` など（Obsidian 本体と同じ書き方） |

## 装飾を付けるときの共通の決まりごと

- 装飾を付けると、前後に半角スペースが自動で入ります。すでに空白がある場合などは入りません。
- 装飾が付いた文字に別の装飾を付けると、重ねて付きます。同じ装飾のボタンを押すと、その装飾だけが外れます。
- コード・数式とほかの装飾は重ねて付けられません。

それぞれの詳しい条件は、[投稿フォームの変更点について（v3.0.0 以降）](./Ver3.0.0以降の投稿フォームについて.md) の「5. ツールバーによる装飾ルール」をご覧ください。
