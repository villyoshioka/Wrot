# テンプレートの見出し指定の使い方

デイリーノートのテンプレートにある見出しを **「テンプレートの見出し指定」** で選んでおくと、Wrot の投稿がその見出しの下に追加されます。「今日の記録」のような見出しの下に投稿をまとめたり、ノートの途中に投稿を入れたりできます。

Obsidian 標準のテンプレートに加えて、Templater を使ったテンプレートにも対応しています。

---

## 1. 設定方法

1. Obsidian の設定の **「デイリーノート」** で、**「テンプレートファイルの場所」** にテンプレートを指定します。
2. Wrot の設定の「基本設定」セクションにある **「テンプレートの見出し指定」** を開きます。
3. 一覧から、投稿を追加したい見出しを選びます。

- **指定なし**: 初期状態です。これまでどおり、投稿はノートの末尾に追加されます。
- 一覧は設定画面を開くたびにテンプレートから読み直されます。テンプレートを書き換えたあとは、設定画面を開き直してください。

---

## 2. 投稿が追加される場所

投稿は、選んだ見出しのまとまりの最後に追加されます。

- まとまりは、選んだ見出しから次の同じ階層か、より上の階層の見出しの手前までです。
- 同じ日に続けて投稿すると、前の投稿の下に順に追加されます。
- 投稿の前後には空行が1行ずつ入ります。
- 同じ見出しが複数ある場合は、ノートの上にあるほうに追加されます。
- 投稿の本文に書いた見出しや、コードブロックの中の見出しは対象になりません。

---

## 3. 変数を含む見出し

テンプレートの見出しに日付などの変数が入っていても選べます。

### 一覧での表示

一覧には、変数が日付などに置き換わる前の、テンプレートに書いたままの文字が表示されます。見出しの記号（`#`）は表示されません。

たとえば、テンプレートに次の見出しがある場合、

```markdown
## <% tp.date.now("YYYY-MM-DD") %>の記録
```

一覧には `<% tp.date.now("YYYY-MM-DD") %>の記録` と表示されます。

### Obsidian 標準のテンプレートの変数

`{{date}}` などの変数は、投稿先のノートの日付に置き換えてから見出しを探します。

### Templater の変数

- `<% tp.date.now("YYYY-MM-DD") %>の記録` のように変数以外の文字を含む見出しは、その文字を手がかりに探します。
- 見出し全体が変数の場合は、次の書き方なら Wrot が読み取って、実際に表示される見出しを探します。
  - `tp.date.now`、`tp.date.today`、`tp.date.tomorrow`、`tp.date.yesterday`
  - `tp.file.title`
- 過去の日付のノートに投稿した場合にも見つけられるように、投稿先のノートの日付と今日の日付の両方で探します。
- 見出し全体が上記以外の書き方の変数だけでできている場合（例: `<% tp.file.folder() %>`）は、手がかりになる文字がないため一覧に表示されません。

---

## 4. Templater を使う場合

Templater でテンプレートの変数を置き換えるには、Templater の設定の「File creation」にある **「Trigger Templater on new file creation」** を、使う端末それぞれでオンにしてください。端末ごとに保存される設定です。

この設定がオンの場合、Wrot が投稿のためにデイリーノートを新しく作ったときは、Templater の処理が終わってから投稿を追加します。

- その日の最初の投稿だけ、表示されるまで少し時間がかかります。
- 新しく作られたノートに Templater の処理がかかるとき、投稿の本文は巻き込まれません。

---

## 5. 見出しやテンプレートが見つからないとき

### ノートに見出しがない場合

投稿はノートの末尾に追加され、「このノートには設定した見出しが無いため、末尾に追加しました」とお知らせが表示されます。

- お知らせが表示されるのは、見出しを選んでから最初の1回だけです。見出しを選び直すと、また1回表示されます。
- 見出しの設定は解除されません。見出しがあるノートには、引き続き見出しの下に追加されます。

### テンプレートが見つからない場合

デイリーノートのテンプレートが指定されていないか、ファイルが見つからない状態で投稿すると、テンプレートの見出し指定は「指定なし」に戻り、お知らせが表示されます。投稿はノートの末尾に追加されます。

### 設定画面での表示

次の場合、「テンプレートの見出し指定」は「指定なし」のまま選択できなくなります。

- デイリーノートのテンプレートが指定されていない
- 指定されたテンプレートのファイルが見つからない
- テンプレートに、一覧に表示できる見出しがない

選んでいた見出しがテンプレートからなくなった場合も、設定画面を開いたときに「指定なし」に戻ります。

---

## 6. タイムラインの並び順

タイムラインは、ノートの中の位置に関係なく、投稿した時刻の新しい順に並びます。

---

## 困ったときは

### 一覧に見出しが表示されない

- Obsidian の設定の「デイリーノート」で、テンプレートが指定されているか確認してください。
- テンプレートに `## 見出し` のような見出しがあるか確認してください。
- 見出し全体が Wrot の読み取れない Templater の変数でできている場合は、表示されません。見出しに変数以外の文字を加えると表示されるようになります。
- テンプレートを書き換えた場合は、設定画面を開き直してください。

### 投稿が見出しの下に追加されない

- 投稿先のノートに、選んだ見出しがあるか確認してください。

### ノートの見出しが変数のまま表示される

- Templater の設定で「Trigger Templater on new file creation」がオンになっているか確認してください。端末ごとの設定のため、別の端末でオンにしていても反映されません。
