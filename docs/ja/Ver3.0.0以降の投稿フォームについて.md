# 投稿フォームの変更点について（v3.0.0 以降）

v3.0.0 から、投稿フォームは Markdown の記号を隠し、太字やリスト、チェックボックスなどを仕上がりの見た目のまま入力できるようになりました。SNS に投稿する感覚で書けます。

ツールバーのボタンについては [装飾の使い方](./装飾の使い方.md) をご覧ください。

> **保存されるノートの内容は変わりません**
>
> 記号が隠れるのはフォーム上の表示だけです。ノートにはこれまでどおり Markdown のまま保存されるため、過去の投稿やタイムライン、Obsidian でのノートの表示には影響しません。

---

## 1. 装飾される要素とそのまま表示される要素

| 要素                                          | フォームでの見え方                                     |
| :-------------------------------------------- | :----------------------------------------------------- |
| **太字・斜体・取り消し線・ハイライト**        | 記号が隠れ、装飾された文字で表示されます               |
| **インラインコード**                          | バッククォートが隠れ、コードスタイルで表示されます     |
| **文中数式**（`$…$`）                         | ドル記号が隠れ、数式として表示されます                 |
| **リンク**                                    | カッコや URL が隠れ、テキストだけがアクセントカラーで表示されます |
| **タグ**                                      | 入力し終えるとアクセントカラーで表示されます           |
| **リスト・チェックリスト・番号付きリスト**    | 記号が隠れ、バレット・チェックボックス・番号で表示されます |
| **引用**                                      | `>` の代わりに左側の引用ラインで表示されます           |
| **コードブロック・数式ブロック**              | 記号も含め、入力したとおりに表示されます               |
| **手動入力の画像埋め込み**（`![[画像.png]]`） | 記号も含め、入力したとおりに表示されます               |
| **URL の直書き**                              | 入力したまま、アクセントカラーで表示されます           |

※ チェックボックスはフォーム上でクリック（タップ）して、直接オン／オフを切り替えられます。

## 2. Markdown 記号を手入力した場合の挙動

`**太字**` のように記号を手で入力した場合、その行で `Enter` を押すまでは記号が表示されたままです。

- **`Enter` を1回押す**: 改行せずに、文字を装飾して記号を隠します。
- **`Enter` を2回押す**: 改行します。
- **`Shift + Enter`**: 記号を表示したまま改行します。

※ 下書きを復元したときや過去の投稿を編集で開いたときは、開いた時点で記号が隠れています。

### 括弧と引用符の自動補完

`(`・`[`・`{`・`"`・`'` を入力すると、閉じる側が自動で入り、カーソルはその間に置かれます。

- 閉じる側を自分で入力しても二重には入らず、すでにある閉じる側の後ろへカーソルが移ります。
- 文字を選んだ状態で入力すると、選んだ文字が括弧や引用符で囲まれます。
- 中身が空の括弧の間で `Backspace` を押すと、両側がまとめて消えます。
- don't のように文字や数字の直前・直後で `'` や `"` を入力したときは、閉じる側は入りません。
- Obsidian の設定「括弧を自動的にペアリング」をオフにしている場合は、自動で入りません。

## 3. 文字の削除方法

### 太字・斜体・取り消し線・ハイライト・リンク

普通の文字と同じように1文字ずつ消せます。記号だけが残ったり、隠れている記号だけが消えたりすることはありません。装飾されている文字をすべて消すと、記号も一緒に消えます。

### インラインコード・文中数式

インラインコードや数式の直後、または内部で `Backspace` を押すと、隠れていた記号がいったん表示され、カーソルは閉じ記号の後ろに移ります。そこからは普通の文字として編集でき、その行で `Enter` を押すとまた記号が隠れます。

### リスト・チェックリスト・番号付きリスト・引用

項目や引用行の先頭（記号の前後どちらでも）で `Backspace` を押すと、次の順に動きます。

1. インデントされている項目は1段浅くなります。
2. いちばん浅い階層では、記号が表示された状態に戻ります。そこからは普通の文字として消せます。

## 4. 装飾の境界での入力

装飾された文字の始まりや終わりにカーソルを置いて入力すると、その文字は装飾の外側に入ります。装飾の内側に文字を足したいときは、装飾された文字の途中にカーソルを置いて入力してください。

- **日本語入力**: 確定した時点で装飾の外側に入ります。未確定の間は装飾が付いて見えることがありますが、リンクは通常の文字色のままです。
- **リンクテキストの変更**: リンクの文字をすべて消してから打ち直すと、リンクの外側の普通の文字として扱われます。リンクの文言を変えたいときは、少なくとも1文字残したまま編集してください。

※ 矢印キーでは、隠れている記号を飛ばして、表示されている文字ごとにカーソルが動きます。

## 5. ツールバーによる装飾ルール

### 前後の半角スペース自動挿入

ツールバーから装飾（太字・斜体・取り消し線・ハイライト・インラインコード・数式・リンク）を付けると、前後に半角スペースが自動で入ります。記号どうしがくっついて表示が崩れるのを防ぐためです。

- 前後にすでにスペースや改行があるときと、行頭では入りません。リスト記号や引用記号 `>` の直後も同じです。
- すでにある装飾の内側に別の装飾を重ねるときも入りません。

### 装飾の重ねがけ

装飾されている文字を選んで別の装飾ボタンを押すと、「太字＋ハイライト」や「取り消し線＋カラーハイライト」のように、内側に重ねて付きます。

- すでに付いている装飾のボタンをもう一度押すと、ほかの装飾は残したまま、その装飾だけが外れます。
- 先に文字を選んでおけば、太字と斜体を同時に付けられます。文字を選ばずにボタンを押したときは、どちらか一方だけです。
- リンクテキストを選んで装飾すると、装飾はリンクの外側に付きます。

### コード・数式への重ねがけの制限

- カーソルや選択範囲がインラインコードや数式にかかっているときは、ほかの装飾ボタン（太字・斜体・取り消し線・ハイライト・リンク）がグレーになって押せなくなります。
- 選択範囲がほかの装飾やリンクにかかっているときは、コード・数式のボタンが押せなくなります。
- コードや数式の中の文字を選んで同じボタンを押すと、その装飾を外せます。

### 文字を選ばずに太字・斜体を押したとき

文字を選ばずに太字や斜体のボタンを押すと、そのあと入力する文字にその装飾が付きます。もう一度押すとオフになります。

- 文字を入力する前に `Backspace` を押すと取り消せます。
- オンのまま投稿すると、行末で自動的に閉じてから投稿されます。

## 6. リストと引用の操作

### リスト

| キー操作                    | 動作                                                         |
| :-------------------------- | :----------------------------------------------------------- |
| `Enter`                     | 次の行もリストを続けます（番号付きリストは番号が自動で振られます） |
| 空白の項目で `Enter`        | 階層を1段浅くします。いちばん浅い階層ではリストを終えます    |
| `Tab` / `Shift + Tab`（PC） | 階層を深く／浅くします（子の項目も一緒に動きます）           |
| 項目の先頭で `Backspace`    | 階層を1段浅くします。いちばん浅い階層では記号が表示された状態に戻します |
| `Shift + Enter`             | リストを続けずに改行します                                   |

※ 番号付きリストは、階層を変えたり項目を追加・削除したりすると、番号が自動で振り直されます。

### 引用

| キー操作               | 動作                                                       |
| :--------------------- | :--------------------------------------------------------- |
| `Enter`                | 次の行も同じ深さで引用を続けます                           |
| 空白の引用行で `Enter` | 階層を1段浅くします。いちばん浅い階層では引用を終えます    |
| `Shift + Enter`        | 引用を続けずに改行します                                   |

### 引用内のリスト

引用行でリストボタンを押すと、`>` の直後にリスト記号が入り、引用の中にリストを作れます。`Enter` での継続、インデント、自動採番も通常のリストと同じように動きます。

## 7. リンクの追加と編集

リンクは、ツールバーの「⋯」メニュー内にある **リンク** から操作します。

- **新しくリンクを追加する**: リンクにしたい文字を選んでボタンを押します。
- **既存のリンクを編集する**: リンクテキストを選ぶか、リンクの中にカーソルを置いてボタンを押します。

フォームの下に入力欄が表示されます。**ノート名** か **URL** を入力し、`Enter` で確定してください。

- ノート名を入力すると候補の一覧が表示され、矢印キーやタップで選べます。`Enter` を押すと、入力中の文字で確定します。
- `https://`・`http://`・`obsidian://` で始まる入力は外部リンク、それ以外は Vault 内のノートへのリンクとして扱われます。
- 既存のリンクを編集しているときは、入力欄の右側にある **リンクを解除** ボタンでリンクを外せます。

#### リンクの保存形式

| リンク先         | 保存形式                                                                            |
| :--------------- | :---------------------------------------------------------------------------------- |
| Vault 内のノート | `![[ノート名\|表示テキスト]]`（表示テキストがノート名と同じ場合は `![[ノート名]]`） |
| 外部 URL         | `[表示テキスト](URL)`                                                               |

※ 内部リンクの使い方は [画像・リンク・埋め込みの使い方](./画像・リンク・埋め込みの使い方.md) をご覧ください。

## 8. 過去の投稿の引用（引用カード）

投稿メニューから **投稿を引用** を選ぶと、その投稿がフォームの下にカードとして表示されます。フォームに本文を入力して、カードと一緒に投稿できます。

- カード右上の **×** ボタンで引用を外せます。
- 引用の記号は投稿するときに付くので、フォームの本文には入りません。
- 下書きには引用カードも保存されます。

## 困ったときは

### 記号が隠れずに表示されたままになる

- 手入力した Markdown 記号は、その行で `Enter` を押すまで隠れません。
- コードブロック、数式ブロック、手入力の画像埋め込み、URL の直書きなどは、入力したとおりに表示されます。

### 装飾のすぐ隣に入力した文字が装飾の外側に入ってしまう

- 装飾の始まりや終わりで入力した文字は、装飾の外側に入ります。装飾の中に文字を足したいときは、途中にカーソルを置いて入力してください。

### ボタンがグレーアウトして押せない

- カーソルや選択範囲が、インラインコード・数式、またはほかの装飾やリンクにかかっていないか確認してください（詳しくは「5. ツールバーによる装飾ルール」）。
- 取り消し線とハイライトは、文字を選んでいるときだけ使えます。リンクは、文字を選んでいるときか、リンクの中にカーソルがあるときだけ使えます。
- 文字を選ばずに太字か斜体の一方をオンにしている間は、もう一方は押せません。
