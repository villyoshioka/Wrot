# Ver3.0.0 以降の投稿フォームについて

Ver3.0.0 より、投稿フォームは Markdown 記号を隠し、仕上がりに近い見た目のまま入力できるようになりました。
太字やリスト、チェックボックスなどがそのまま視覚的に反映されるため、SNS の投稿欄に近い直感的な感覚で執筆できます。

ここでは、Ver3.0.0 以降の投稿フォームにおける入力・削除の挙動や、知っておくと便利な仕様について解説します。ツールバーのボタン一覧は [装飾の使い方](./装飾の使い方.md) をご覧ください。

> **ノートに保存される内容は今までと変わりません**
>
> 記号が隠れるのはフォーム上の表示のみで、ノートには従来どおりプレーンな Markdown 形式で保存されます。過去の投稿やタイムライン、ノート側の表示に影響はありません。

---

## 1. 記号が隠れる要素・そのまま表示される要素

| 要素                                          | フォームでの表示                                     |
| :-------------------------------------------- | :--------------------------------------------------- |
| **太字・斜体・取り消し線・ハイライト**        | 記号を隠し、装飾された見た目で表示                   |
| **インラインコード**                          | 記号を隠し、コードスタイルで表示                     |
| **文中数式**（`$…$`）                         | 記号を隠し、レンダリングされた数式で表示             |
| **リンク**                                    | 記号を隠し、表示テキストのみをアクセントカラーで表示 |
| **タグ**                                      | 書き終えるとアクセントカラーで表示                   |
| **リスト・チェックリスト・番号付きリスト**    | 記号の代わりにバレット・チェックボックス・番号を表示 |
| **引用**                                      | `>` の代わりに左側の引用ラインで表示                 |
| **コードブロック・数式ブロック**              | 記号を含め、入力したままの形式で表示                 |
| **手動入力の画像埋め込み**（`![[画像.png]]`） | 記号を含め、入力したままの形式で表示                 |
| **URL 直書き**                                | 入力したままの形式で、アクセントカラーで表示         |

※ チェックボックスは、フォーム上でクリック（タップ）して直接オン／オフを切り替えられます。

## 2. Markdown 記号を手入力した場合の挙動

`**太字**` などの記号を手動で入力した場合、その行で **Enter キーを押すまで記号が表示されたまま** になります。入力途中で自動的に装飾へ切り替わることはありません。

- **1回目の `Enter`**: 記号が隠れ、装飾された見た目に変換されます（改行はされません）。
- **2回目の `Enter`**: 改行します。
- **`Shift + Enter`**: 変換を行わず、そのまま改行します。

※ 下書きの復元時や、過去の投稿を編集で開いた際は、最初から記号が隠れた状態で表示されます。

### 括弧と引用符

`(`・`[`・`{`・`"`・`'` を入力すると、閉じる側が自動で入り、カーソルはその間に置かれます。

- 閉じる側を入力すると、記号は増えずに、すでに入っている閉じる側の後ろへカーソルが移ります。
- 文字を選んだ状態で入力すると、選んだ文字が括弧や引用符で囲まれます。
- 何も入力していない括弧の間で `Backspace` を押すと、両側がまとめて消えます。
- 文字の直後で `'` や `"` を入力したとき（don't など）と、文字の直前で入力したときは、閉じる側は入りません。
- Obsidian の設定「括弧を自動的にペアリング」をオフにしている場合は、自動で入りません。

## 3. 文字の削除方法

### 太字・斜体・取り消し線・ハイライト・リンク

通常のテキストと同様に、表示されている文字だけが削除されます。記号だけが残ったり、記号のみが消えたりすることはありません。装飾内の文字をすべて削除すると、記号自体も自動で消去されます。

### インラインコード・文中数式

装飾の直後（または内部）で `Backspace` を押すと、**一度元の記号が表示された状態に戻り**、カーソルが閉じ記号の後ろに配置されます。そこから通常のテキストとして編集可能になり、その行で `Enter` を押すと再び記号が隠れます。

### リスト・チェックリスト・番号付きリスト・引用

項目の先頭（記号の前後いずれか）で `Backspace` を押すと、以下の順序で動作します。

1. インデントされている項目は、**1段階浅く** なります。
2. 最も浅い階層の場合、**記号が表示された状態** に戻ります。以降は通常のテキストとして削除できます。

## 4. 装飾の境界で文字を入力する場合

太字・ハイライト・リンクなどの **開始位置または終了位置で文字を入力すると、装飾の外側に入力されます**。装飾の途中で入力した文字は、装飾の内側に含まれます。

- **日本語入力の挙動**: 文字を確定した段階で装飾の外側に配置されます。変換前の未確定状態では装飾スタイルが適用されて見える場合があります（リンクは未確定時も通常色で表示されます）。
- **リンクの再入力**: リンクテキストをすべて削除してから打ち直すと装飾の外側扱いになります。リンクテキストを修正したい場合は、文字をすべては消さずに、一部を残したまま編集してください。

※ 矢印キーでカーソルを移動する際は、隠れている記号をスキップし、表示されている文字単位で移動します。

## 5. ツールバーによる装飾ルール

### 前後の半角スペース自動挿入

ツールバーから各種装飾（太字・斜体・取り消し線・ハイライト・インラインコード・数式・リンク）を適用すると、記号同士の干渉によるレイアウト崩れを防ぐため、前後に半角スペースが自動挿入されます。

- すでに前後に空白・改行がある場合や行頭では挿入されません。リスト記号や引用符 `>` の直後も同様です。
- 既存の装飾の内側に重ねがけする場合も挿入されません。

### 装飾の重ねがけ

装飾済みの文字列を選択して別の装飾ボタンを押すと、**内側に重ねて適用** されます（例: 太字＋ハイライト、取り消し線＋カラーハイライト）。

- すでに適用されている装飾ボタンを再度押すと、**その装飾のみが解除** され、他の装飾は保持されます。
- 太字と斜体は、選択範囲に対しては同時に適用できます（文字を選ばずに押したときはどちらか一方のみ）。
- リンクテキストを選択して装飾した場合、リンクの外側から装飾が適用されます。

### コード・数式への重ねがけ制限

- 選択範囲やカーソル位置がインラインコードまたは数式にかかっている場合、その他の装飾ボタン（太字・斜体・取り消し線・ハイライト・リンク）は非活性（グレーアウト）になります。
- 選択範囲がすでに他の装飾やリンクにかかっている場合、コード・数式ボタンは非活性になります。
- コード（または数式）内部を選択した状態で該当ボタンを押すと、装飾を解除できます。

### 文字を選ばずに太字・斜体を押したとき

範囲選択をせずに太字・斜体のボタンを押すと、続けて入力する文字にその装飾が適用されます。再度ボタンを押すと装飾を閉じます。

- 文字を入力せずに `Backspace` を押すと、キャンセルできます。
- 装飾を閉じずにそのまま投稿した場合、行末で自動的に装飾が閉じられて投稿されます。

## 6. リストと引用の操作

### リスト

| キー操作                    | 挙動                                                     |
| :-------------------------- | :------------------------------------------------------- |
| `Enter`                     | 次の行に同じリスト項目を継続（番号付きリストは自動採番） |
| 空白の項目で `Enter`        | 階層を1段上げ、最上位階層の場合はリストを終了            |
| `Tab` / `Shift + Tab`（PC） | インデントを1段下げる / 1段上げる。子の項目も一緒に動く |
| 項目の先頭で `Backspace`    | 階層を1段上げる（最上位階層では記号を表示状態に戻す）    |
| `Shift + Enter`             | リストを継続せずに通常の改行を挿入                       |

※ 番号付きリストは、階層の変更や項目の追加・削除に応じて番号が自動で振り直されます。

### 引用

| キー操作               | 挙動                                        |
| :--------------------- | :------------------------------------------ |
| `Enter`                | 次の行も同じ深さの引用を継続                |
| 空白の引用行で `Enter` | 階層を1段上げ、最上位階層の場合は引用を終了 |
| `Shift + Enter`        | 引用を継続せずに通常の改行を挿入            |

### 引用内のリスト

引用行でリストボタンを押すと、`>` の直後にリスト記号が挿入され、引用内にリストを作成できます。`Enter` による継続やインデント操作、自動採番も通常のリストと同様に動作します。

## 7. リンクの挿入と編集

リンクはツールバーの「⋯」メニュー内にある **リンク** から設定します。

- **新規作成**: リンク化したいテキストを選択した状態でボタンを押します。
- **既存リンクの編集**: リンクテキストを選択するか、リンク上にカーソルを置いてボタンを押します。

フォーム下部にポップアップ入力欄が表示されるため、**ノート名** または **URL** を入力して `Enter` で確定します。

- ノート名を入力すると候補一覧が表示され、矢印キーまたはタップで選択できます（`Enter` を押すと入力中の文字列で確定します）。
- `https://`・`http://`・`obsidian://` で始まる入力は外部リンク、それ以外は Vault 内のノートリンクとして扱われます。
- 既存リンクの編集中は、入力欄の右側にある **リンクを解除** ボタンからリンクを外せます。

#### 保存フォーマット

| リンク先         | 保存形式                                                                          |
| :--------------- | :-------------------------------------------------------------------------------- |
| Vault 内のノート | `![[ノート名\|表示テキスト]]`（表示テキストがノート名と同じ場合は `![[ノート名]]`） |
| 外部 URL         | `[表示テキスト](URL)`                                                             |

※ 内部リンクの構文に関する詳細は [画像・リンク・埋め込みの使い方](./画像・リンク・埋め込みの使い方.md) をご確認ください。

## 8. 投稿の引用（引用カード）

投稿メニューから **投稿を引用** を選択すると、対象の投稿がフォーム下部にカード形式で表示されます。カードの上で本文を入力し、そのまま投稿できます。

- カード右上の **×** ボタンで引用を解除できます。
- 引用記号は投稿実行時に付与されるため、フォームの本文テキストには混入しません。
- 下書き保存時も引用カードの状態がそのまま保持されます。

## よくある質問・トラブルシューティング

### 記号が隠れずに表示されたままになる

- 手入力した Markdown 記号は、その行で `Enter` を押すまで変換されません。
- コードブロック・数式ブロック、手書きの画像埋め込み、URL の直書きなどは、仕様上プレーンテキストのまま表示されます。

### 装飾の続きを入力したいのに、装飾の外側に入ってしまう

- 装飾文字列の先頭および末尾で入力した文字は、外側に配置される仕様です。装飾内に文字を追加したい場合は、文字列の途中にカーソルを置いて入力してください。

### ボタンがグレーアウトして押せない

- カーソルまたは選択範囲がインラインコード・数式、もしくはすでに別の装飾やリンクにかかっていないか確認してください（詳細は「5. ツールバーによる装飾ルール」を参照）。
- 取り消し線・ハイライトは範囲選択時のみ有効です。リンクは範囲選択中、または既存リンク上にカーソルがある場合のみ操作できます。
- 太字・斜体は、文字を選ばずに押したもう一方が点灯している間は押せません。
