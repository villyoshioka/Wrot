# 画像・リンク・埋め込みの使い方

Wrot では、Obsidian の標準的な Markdown 記法をそのまま活かして、画像の表示、ノートへのリンク、外部 Web サイトの OGP プレビューをシームレスに扱えます。

ここでは、各要素の挿入方法、プレビューの表示仕様、および設定まわりのポイントについて解説します。

---

## 1. 📎 埋め込みボタンの基本操作

ツールバーにある **📎（埋め込みボタン）** は、画像やノートの内部リンクを手軽に挿入するためのショートカットです。

- **新規挿入**: 選択範囲がない状態で押すと `![[ ]]` が挿入され、括弧の内部にカーソルが配置されます。そのまま対象のファイル名やノート名を入力してください。
- **テキストの囲み**: すでに入力した文字列を選択した状態で押すと、そのテキストが自動的に `![[ ]]` で囲まれます。
- **囲みの解除**: すでに `![[ ]]` または `[[ ]]` で囲まれた文字列を選択して押すか、カーソルが括弧内にある状態（ボタン点灯時）でもう一度押すと、囲みを解除できます。

---

## 2. 画像の添付（貼り付け・D&D）

スクリーンショットや写真ファイルを投稿フォームへ直接添付できます。

### 添付する 3 つの方法

1. **画像ボタン（🖼️）**: ファイル選択ダイアログを開き、端末内の画像ファイルを選択します。
2. **クリップボードからの貼り付け**: 画面キャプチャや画像編集アプリでコピーした画像を、そのままフォームへペースト（`Ctrl + V` / `Cmd + V`）します。
3. **ドラッグ＆ドロップ**: 画像ファイルを投稿エリアへ直接ドラッグ＆ドロップします。

### 保存先とファイル名のルール

- **保存のタイミング**: 画像ファイルは**投稿を確定したタイミングで Vault 内へ保存**されます（投稿をキャンセルした場合は保存されません）。
- **保存先ディレクトリ**: 原則として Obsidian 本体の「設定 → ファイルとリンク → 添付ファイルの保存先」に準拠します。
  - Wrot の設定で「画像の保存先を指定」を有効にすると、Wrot 経由で添付した画像のみを専用フォルダへ振り分けることも可能です（※指定フォルダが存在しない場合は本体設定の保存先へフォールバックします）。
- **ファイル名**: `Pasted Image YYYYMMDDHHmmss.<拡張子>` の形式で自動的にリネーム・保存されます。

### 注意事項

- **添付上限**: 1つのメモにつき添付できる画像は **1枚まで** です。
- **対応フォーマット**:
  - 画像ボタン経由: `PNG` / `JPEG` / `GIF`
  - 貼り付け・ドラッグ＆ドロップ経由: 上記に加え、`WebP` / `SVG` / `BMP` にも対応
- **OS のファイルコピーについて**: Finder やエクスプローラー上でファイル自体を「コピー」して貼り付ける操作には対応していません。PC 内の画像を追加する場合は、画像ボタンまたはドラッグ＆ドロップをご利用ください。

## 3. 手書きによる画像埋め込み

すでに Vault 内にある画像や、Web 上の画像を直接コードで記述して埋め込むことも可能です。

### Vault 内の画像（推奨）

```markdown
![[photo.png]]
```

Vault 内に該当ファイルが存在すれば、インラインで画像プレビューが表示されます。
（対応拡張子: `png`, `jpg`, `jpeg`, `gif`, `svg`, `webp`, `bmp`）

### Web 上の画像 URL

```text
https://example.com/photo.png
```

末尾が画像拡張子の URL は、URL プレビュー機能の ON/OFF に関わらず自動的に画像としてインライン表示されます。

### Obsidian URL 形式

```text
obsidian://open?vault=MyVault&file=photo.png
```

指定された Vault 内の画像が正しく解決できれば画像として表示され、解決できない場合は通常のリンクとして表示されます。

---

## 4. ノート間リンク

Vault 内の他ノートへのリンクも同様に記述できます。

```markdown
![[ノート名]]
[[ノート名]]
```

※ 📎 ボタンで挿入されるのは `![[ ]]` 形式です。通常のテキストリンク `[[ ]]` にしたい場合は直接手書きしてください。どちらの形式でもクリックすることで該当ノートへ移動できます。

---

## 5. Web サイトの OGP プレビュー

外部 URL を記述した際、リンク先ページのタイトルやサムネイルを含んだカード形式（OGP カード）でプレビュー表示できます。

### プレビューカードが表示される条件

- Wrot の設定で **「URL プレビュー」** が有効になっている
- `http://` または `https://` から始まる URL である
- リンク先サーバーからタイトルや概要文などの OGP 情報が正常に取得できる

### プレビューカードが表示されないケース

- 設定で「URL プレビュー」が無効になっている場合
- `obsidian://` 形式の内部 URL の場合
- 画像への直リンク URL の場合（カードではなく画像本体が表示されます）
- リンク先がアクセス制限されている、または OGP 情報を返さない場合

### X（旧 Twitter）の投稿リンク

`https://twitter.com/...` および `https://x.com/...` の投稿 URL は、自動的に専用のカードデザインで整形して表示されます。

---

## 困ったときは

### 画像が正しく表示されない

- ファイル名や拡張子が Vault 内のファイルと完全に一致しているか確認してください。
- `![[ ]]` の閉じ括弧が欠けていないか確認してください。
- 対応外の画像フォーマットではないか確認してください。

### URL プレビュー（OGP カード）が表示されない

- Wrot の設定で「URL プレビュー」が ON になっているか確認してください。
- リンク先の Web サイトが OGP（メタタグ）に対応しているかご確認ください。
- 画像ファイルへの直リンクの場合は、カードではなく画像プレビューとして表示されます。
