# 画像・リンク・埋め込みの使い方

Wrot では Obsidian の Markdown 記法のまま、画像の表示、ノートへのリンク、Web サイトの OGP プレビューを使えます。

---

## 1. リンクボタンの基本操作

「⋯」メニューにある **リンク** から、Vault 内のノートや Web ページへのリンクを付けられます。

- 新しく付けるときは、リンクにしたい文字を選んでから押します。
- 今あるリンクを直すときは、リンクの文字を選ぶか、リンクの上にカーソルを置いてから押します。

押すとフォームの下に入力欄が開きます。**ノート名** または **URL** を入力して `Enter` で確定します。

- ノート名を打つと候補が表示され、矢印キーかタップで選べます。`Enter` を押すと、打った文字のまま確定します。
- `https://`・`http://`・`obsidian://` で始まるものは外部へのリンク、それ以外は Vault 内のノートへのリンクになります。
- 今あるリンクを直すときは、入力欄の右にある **リンクを解除** ボタンでリンクを外せます。

投稿フォームでは、リンクは表示する文字だけがアクセントカラーで表示されます。保存される形式は次のとおりです。

| リンク先         | 保存される形式                                                              |
| :--------------- | :-------------------------------------------------------------------------- |
| Vault 内のノート | `![[ノート名\|表示する文字]]`（表示する文字がノート名と同じなら `![[ノート名]]`） |
| 外部の URL       | `[表示する文字](URL)`                                                       |

> **v3.0.0 での変更**
>
> 以前の 📎（埋め込み）ボタンはリンクボタンにまとまりました。ツールバーの配置をカスタマイズしていた場合も、📎 ボタンは自動で削除されます。

## 2. 画像の添付

### 添付する 3 つの方法

1. **画像ボタン（🖼️）**: ファイル選択ダイアログから端末内の画像ファイルを選びます。
2. **クリップボードからの貼り付け**: スクリーンショットや画像編集アプリでコピーした画像を、投稿フォームに貼り付けます（`Ctrl + V` / `Cmd + V`）。
3. **ドラッグ＆ドロップ**: 画像ファイルを投稿フォームへドラッグ＆ドロップします。

### 保存先とファイル名のルール

- 画像は**投稿したときに Vault 内へ保存**されます。投稿をキャンセルした場合は保存されません。
- 保存先は、基本的に Obsidian 本体の「設定 → ファイルとリンク → 添付ファイルの保存先」に従います。
  - Wrot の設定で「画像の保存先を指定」を有効にすると、Wrot で添付した画像だけを別のフォルダに保存できます。指定したフォルダがない場合は、本体設定の保存先に保存されます。
- ファイル名は `Pasted Image YYYYMMDDHHmmss.<拡張子>` の形式に変わります。
- 初期状態では、添付した画像を圧縮し、位置情報などの付属データを削除してから保存します。Wrot の設定「画像を圧縮して保存」をオフにすると、圧縮せずに保存されます。
  - 圧縮後の形式は WebP です。iPhone・iPad では WebP を書き出せないため、JPEG または PNG（透過あり）になります。
  - GIF など動く画像と、圧縮しても小さくならない画像は、元のまま保存されます。

### 注意事項

- 1つの投稿に添付できる画像は **1枚まで** です。
- 対応している形式は次のとおりです。
  - 画像ボタン: `PNG` / `JPEG` / `GIF`
  - 貼り付け・ドラッグ＆ドロップ: 上記に加えて `WebP` / `SVG` / `BMP`
- Finder やエクスプローラーでファイル自体を「コピー」して貼り付ける操作には対応していません。PC 内の画像を追加する場合は、画像ボタンかドラッグ＆ドロップを使ってください。

## 3. 手書きによる画像埋め込み

Vault 内にある画像や Web 上の画像を、記法を直接書いて埋め込むこともできます。

### Vault 内の画像（推奨）

```markdown
![[photo.png]]
```

Vault 内にそのファイルがあれば、投稿の中に画像が表示されます。対応している拡張子は `png`, `jpg`, `jpeg`, `gif`, `svg`, `webp`, `bmp` です。

### Web 上の画像 URL

```text
https://example.com/photo.png
```

末尾が画像の拡張子の URL は、URL プレビューの ON/OFF に関係なく、画像として表示されます。

### Obsidian URL 形式

```text
obsidian://open?vault=MyVault&file=photo.png
```

指定した Vault 内の画像が見つかれば画像として表示され、見つからない場合は通常のリンクとして表示されます。

## 4. ノート間リンク

Vault 内のほかのノートへのリンクは、リンクボタンのほかに手書きでも書けます。

```markdown
![[ノート名]]
![[ノート名|表示する文字]]
[[ノート名]]
```

- `|` の後ろに文字を書くと、ノート名の代わりにその文字が表示されます。
- どの形式でも、クリックするとそのノートへ移動します。存在しないノートへのリンクは薄い斜体で表示され、クリックするとそのノートを作成します。
- 投稿内のノートへのリンクは、Obsidian 本体のリンクと同じくグラフビューとバックリンクに反映され、ノート名を変更すると自動で書き換わります。

---

## 5. Web サイトの OGP プレビュー

外部の URL を書くと、リンク先ページのタイトルやサムネイルが入ったカード（OGP カード）で表示できます。

### プレビューカードが表示される条件

- Wrot の設定で **「URL プレビュー」** が有効になっている
- `http://` または `https://` から始まる URL である
- リンク先からタイトルや概要文などの OGP 情報を取得できる

### X（旧 Twitter）の投稿リンク

`https://twitter.com/...` と `https://x.com/...` の投稿 URL は、専用のカードで表示されます。

---

## 困ったときは

### 画像が正しく表示されない

- ファイル名や拡張子が Vault 内のファイルと一致しているか確認してください。
- `![[ ]]` の閉じ括弧が欠けていないか確認してください。
- 手書きの画像埋め込みは、投稿フォームでは記号が表示されたままですが、タイムラインでは画像として表示されます。
- 対応している形式の画像か確認してください。

### URL プレビュー（OGP カード）が表示されない

- Wrot の設定で「URL プレビュー」が ON になっているか確認してください。
- リンク先の Web サイトが OGP（メタタグ）に対応しているか確認してください。
- 画像ファイルへの直リンクの場合は、カードではなく画像プレビューとして表示されます。
