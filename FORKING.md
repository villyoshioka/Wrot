# About Forks

Forks of Wrot are welcome. I'm really glad when people adapt and improve it for their own workflows.

Wrot is released under the MIT license, so you're free to fork it however you like. If you publish your fork, I'd appreciate your cooperation on the points below.

---

## Plugin name and ID

If you keep the original ID, users can't install both plugins in the same vault, and it's hard to tell which one is enabled. Please give your fork its own name and ID.

## Class names and CSS variables

If your class names, CSS variables, and the like are the same as the original's, unexpected bugs may occur when both are enabled. Rather than following the original, please give yours a prefix of your own.

## Version numbers

Matching the original's version numbers or jumping ahead of them makes it hard to tell which build is newer and which version a user is talking about. Please use your own numbering scheme.  
I recommend adding a build tag after the upstream version, such as `3.1.0-fork.1`.

## Credits and descriptions

So that users don't confuse your fork with the official build, please state somewhere in your README or description that it is a fork of Wrot.

## Bug reports

Issues on the main repository are only for bugs in the official build. I can't handle problems caused by changes or new features in a fork, so please handle those bug reports in your own repository.

Thank you for your understanding and cooperation.
